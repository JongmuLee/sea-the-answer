# 통합 질문 사용성 개선

- 상태: 완료
- 요청: 질문/답변 10px 간격, UI 언어, 대화 저장, 입력 옵션 정리, 로고 새 대화, 이력 삭제.
- 범위: 화면 메뉴/안내만 번역. 질문, 답변 본문, 원문 PDF, 보고서 데이터와 AI 동작은 변경하지 않는다.

- [x] 기본 질문 설정 유지 및 선택 메뉴 정리
- [x] UI 언어 사전·선택 모달·브라우저 언어 설정 보관

- [x] 대화 순서 표시와 답변별 근거·보고서 버튼 연결
