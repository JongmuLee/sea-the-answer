# 앱에서 실행하는 여섯 업무 스킬

- 상태: 완료 (로컬 구현·검증, 미제출)
- 작성: 2026-10-15
- 담당: 통합 기능
- 관련: [계약](../specs/workflow-skills.md), [ADR](../adr/0015-optional-model-workflow-skills.md)

## 목표·범위

MRV 분석, 선택 문서 답변, 운항 요약, 보고서 초안, 점검 체크리스트, 질의·응답 평가를 앱에서 선택 실행한다. 정해진 작업은 LLM 없이 실행하고 문서 표현만 선택적으로 기존 OpenAI 호환/Qwen 연결을 활용한다. 새 학습·공식 CII·자동 승인·임의 SQL·모델에 권한 위임은 범위 밖이다.

## 단계

- [x] 여섯 SKILL.md와 고정 서버 실행 계약
- [x] 선택 문서의 권한·개정·검색 범위와 인용 검증
- [x] 기존 MRV 계산 및 앱 운항자료 연결
- [x] 초안 생성과 별도 명시적 저장, 본인 응답 평가
- [x] 스킬 페이지·오류·부족 입력·출처 표시
- [x] 단위·실 PostgreSQL·화면 검증 및 문서 정리

개인 원본 DB와 기존 API는 유지한다. 팀 main에서 분리한 codex/qwen-workflow-skills 브랜치에서 작업하며 원격 푸시·PR은 하지 않는다. 평가용 임시 DB·합성 문서를 사용하고 실제 MRV 표본 검증은 별도 읽기 경로로 수행한다.

## 검증 기록

2026-10-15: 스킬 형식 6개 검증, backend 253 passed / 68 skipped(선택 DB 환경 미설정), 임시 스키마 실 PostgreSQL 스킬·문서 회귀 35 passed, frontend 4 passed와 production build, Docker 브라우저 전체 시나리오 19단계 통과. 별도 Docker 체험 DB에 실제 MRV 80,552행·합성 Noon 4,380행·DWT 참조 25,240행을 적재해 여섯 스킬 HTTP 호출을 확인했다. 매핑한 YEOMAN BANK/2018의 화면 참고값 8.013878을 확인했다. 개인 원본 DB는 변경하지 않았다.

Qwen 2.5 3B의 실제 OpenAI 호환 요청·JSON 응답·범위 보존을 확인했다. 가상 문서 질문에서 모델이 근거 부족으로 보류했으며, 좋은 의미적 답변 품질을 입증한 것으로 기록하지 않는다. 기본 비모델 실행을 유지하고 실제 질문셋 기반 모델 품질 평가는 후속이다. 자연어 자동 스킬 선택·대화 기억·법정 CII는 구현 범위 밖이다.

최종 재검증 중 기존 동시 요청 4개 제한으로 GET /api/reports가 일시적으로 429를 반환한 실행도 있었다. 이를 숨기거나 운영 제한을 완화하지 않고 새 격리 스택에서 다시 확인해 전체 19단계가 35.2초에 통과했다. 이 동시 요청 제한의 일시 응답은 기존 공통 처리의 한계로 남는다.

## 팀 최신 main 재통합 (2026-10-15)

기준 커밋은 024f3b3767133dec32bc817307e86d609b134e79이다. 팀의 기본 법령·핸드북 PDF 및 seed 등록, Mindlogic 호스트별 키 선택·완료 경로, AI 실패 배너 조건, 선택 상자·날짜 입력 보존 수정을 유지한 상태에서 스킬을 통합했다. 변경 이력 충돌은 양쪽 기록을 보존해 해결하고 팀 ADR 0014와 구분하도록 스킬 결정을 0015로 옮겼다. 원격 푸시·PR은 하지 않는다.

재통합 검증: backend 272 passed / 68 skipped(선택 DB 환경 미설정), PostgreSQL 임시 스키마 35 passed, frontend 4 passed, production build 및 Docker 브라우저 19단계 통과(45.3초). 스킬 형식 6개와 추가 Python F 규칙 검사도 통과했다. 테스트 DSN은 SQLAlchemy URL을 psycopg용으로 변환해 사용했다.

## PR #16 호환성 재점검

팀 main 024f3b3과 대조해 보고서 body의 공통 template·ship·from·to 누락과 이력의 문서 검색 오표시를 보완했다. Noon 실제 집계일과 원래 요청 scope를 구분해 보존한다. PostgreSQL 관련 회귀는 36 passed, 전체 backend는 272 passed / 69 skipped, frontend는 4 passed다. Docker 검증에 기존 보고서 열기·기간 표시·이력 재열람을 추가했다. 첫 확장 실행에서는 기존 미저장 초안 보호 확인창을 처리하지 않아 테스트가 멈췄고, 보호 동작을 유지하면서 확인 후 내용을 검증하도록 테스트를 수정했다.

팀 검색 개선 PR #15는 아직 열려 있다. 같은 DocumentStore.search를 수정하므로 그 PR과 통합할 때 document_ids 인자·활성 개정/권한 검사·SQL 단계 문서 제한을 보존해야 한다. 다른 PR 코드를 미리 병합하지 않았다. 스킬 구현은 사용자 요청으로 PR #16에 제출했으며 병합은 하지 않는다.

확장 테스트에서 스킬 저장 후 공통 보고서 목록 캐시가 갱신되지 않는 문제도 재현했다. 저장 성공 시 사용자 식별을 확인해 공통 workspace 목록에 저장 결과를 반영하도록 보완했다. 별도 새로고침 없이 기존 목록에서 제목·기간이 보여야 하는 동작을 검증한다.

보완 완료 후 격리 Docker 전체 19단계가 28.8초에 통과했다. 보고서 저장→기존 편집기 열기(미저장 초안 보호 확인 포함)→목록에서 실제 기간 표시→스킬 응답 이력 열기를 확인했다.
