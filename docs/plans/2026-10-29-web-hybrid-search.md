# 웹 하이브리드 검색 통일

- 상태: 완료
- 작성·담당: Codex · 2026-10-29
- 관련: [검색 계약](../specs/rag-vector.md)

## 1. 배경과 목표

웹 검색은 BM25·벡터 후보를 RRF로 결합하고, 방식별 비교는 개발자 CLI에서 수행한다.

## 2. 범위

검색 진입점·health·Compose·현재 안내만 수정한다. 저장·색인·모델·스키마·답변 생성은 유지한다.
기술 스택과 모듈 경계 변경이 없는 검색 정책 조정이므로 새 ADR은 작성하지 않는다.

## 3. 단계

- [x] 웹 hybrid 고정, CLI 명시적 모드와 fallback 유지. 완료 조건: 환경변수 잔존 회귀 통과.
- [x] 현재 안내·명세 최소 수정. 완료 조건: 설정 선택 예제 제거, 과거 계획·ADR 보존.
- [x] backend 전체·격리 Docker E2E. 완료 조건: 결과·미검증 범위 기록 및 격리 스택 정리.

## 4. 영향 받는 파일·문서

`rag_search.py`, `store/documents.py`, health, Compose·설정 예시, 관련 테스트와 현재 검색 안내.

## 5. 위험과 대응

색인 미준비 시 기존 BM25 fallback과 안전한 로그를 유지한다. 권한·현재 내용은 검색 후 재확인한다.
검증은 격리 DB/컨테이너에서 수행하고 실제 앱을 재시작하지 않는다.
