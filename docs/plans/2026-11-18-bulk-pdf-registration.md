# 관리자 PDF 일괄 등록

- 상태: 완료
- 담당: 문서/RAG
- 관련: [문서 저장 계약](../specs/api.md#4-문서-등록-payload-documentsave)

## 범위와 단계

- [x] 관리자 문서 화면에서 선택한 PDF에 공통값을 적용하고 개별 메타데이터와 추출 본문을 확인한다.
- [x] 파일마다 기존 PDF 추출과 신규 문서 저장 경로를 순차 호출한다. 저장 결과가 불확실하면 같은 논리 ID로 확인한다.
- [x] 합성 PDF로 등록·실패·재시도와 기존 화면을 검증하고 운영 안내에 사용 방법을 기록한다.

파일 선택과 작업 상태는 열린 등록 창에서 관리한다. 서버는 기존 문서별 트랜잭션과 색인 작업을 사용한다.
