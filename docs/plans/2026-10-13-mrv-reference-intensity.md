# MRV 제원 후보 연결과 참고 탄소집약도

- 상태: 완료 (로컬 구현·검증, 미제출)
- 작성: 손태호 · 2026-10-13
- 담당: 역할4
- 관련: [Tool 계약](../specs/tools.md), [데이터 모델](../data-model.md), [ADR 0013](../adr/0013-mrv-reference-intensity.md)

## 목표와 범위

확보한 IMO별 DWT 후보를 MRV 원본과 별도 보존하고, 단일 승인 보고기간의 보고 CO₂와 추정 거리로 참고 탄소집약도를 반환한다. 공식 CII·등급·준수 판정, 원본 덮어쓰기, 화면/LLM 연결과 원격 제출은 제외한다.

## 단계와 완료 조건

- [x] 별도 참조 테이블 migration과 원본 보존 적재 CLI
- [x] Bearer 인증을 유지하는 참고 지표 전용 API
- [x] 출처·제원 충돌·선종·결측·0·복수 보고·비공식 경고 검증
- [x] 격리 PostgreSQL 및 실제 보유 CSV로 연결·산술·원본 불변 검증
- [x] 계약·운영 안내·데이터 모델·검증 기록 갱신

## 위험과 대응

공개 제원과 역산 거리의 미검증 범위를 결과에 명시한다. 출처 간 DWT 5% 초과 충돌, 지원 밖 선종, 결측/비양수 값, 복수 승인 보고는 계산하지 않는다. 참조 테이블을 앱 JSON 백업에 넣지 않으며 기존 MRV/Noon 적재기와 계산 응답은 유지한다. 원본 파일·운영 DB는 변경하지 않고 임시 DB로 검증한다.
