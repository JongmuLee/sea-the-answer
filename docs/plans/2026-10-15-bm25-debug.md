## 1. 배경과 목표

UI에서 등록한 PostgreSQL 청크의 검색 순위·점수·일치 토큰을 기존 검색과 같은 함수로 확인한다.

## 2. 범위

- 포함: CLI, 공통 후보 조회·토큰화 재사용, 문서 필터, Docker 실행, 회귀 테스트.
- 제외: 랭킹 변경, UI/API 필드 변경, DB 쓰기·스키마 변경, 토큰별 기여도, 벡터 검색.

## 5. 위험과 대응

| 위험 | 대응 |
|---|---|
| 제한 문서 노출 | 기본 guest, 명시한 활성 계정의 기존 scope 필터 적용 |
| 실 DB 변경 | READ ONLY 트랜잭션, bootstrap·저장·LLM 호출 없음 |
| 필터 후 점수 오해 | 필터는 corpus 자체를 제한하며 IDF도 바뀐다고 안내 |
| 토큰 일치를 기여도로 오해 | 전체 검색 필드의 교집합임을 명시; 실제 점수는 retrieve 결과 그대로 |

## 6. 열린 질문

- 토큰별 기여도는 후속 작업에서 동일 BM25 인덱스의 단일 토큰 점수로 분리 가능. 이번에는 구현하지 않는다.
