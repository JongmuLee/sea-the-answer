# Chroma 서버 이미지 분리

- 상태: 완료
- 작성: Codex · 2026-10-29
- 담당: 문서/RAG
- 관련: [벡터 검색 계약](../specs/rag-vector.md), [ADR 0019](../adr/0019-local-vector-retrieval.md)

## 1. 배경과 목표

사용자 요청에 따라 Chroma 서버를 backend 이미지 대신 버전을 고정한 공식 전용 이미지로 실행한다.
임베딩은 기존 CPU backend에서 수행하고 검색 모드·RRF·API·DB는 유지한다.

## 2. 범위

- 포함: 이미지/실행 명령·영속 경로·헬스체크 호환성, 기존 볼륨 구조 확인, 문서 갱신.
- 제외: 실행 중인 앱 재시작, 실제 앱 데이터 변경, 의존성 교체, 검색 기본값 변경, 커밋·푸시.

## 3. 단계

- [x] 프로젝트 Docker E2E·관련 RAG 회귀 및 실행 안내·측정 기록.

## 4. 영향 받는 파일·문서

compose.yaml, 필요 시 backend/Dockerfile의 더 이상 쓰지 않는 경로, README 및 docs 운영·구조·계약·ADR·변경 이력.

## 5. 위험과 대응

기존 벡터 경로는 /data/chroma다. 새 이미지 기본 /data에 무심코 연결해 새 DB를 만드는 문제를 피하고,
버전 1.5.9와 저장 경로를 명시한다. 사용자 DB 대신 격리 테스트 볼륨에서 이전 서버 형식 호환성을 확인한다.

## 6. 열린 질문

공식 Rust 서버의 run 옵션·bash 존재·Python/curl 부재를 실제 이미지에서 확인했다.
