# UI 이전 기록 — 1.3.0 · Next.js

2026-10-05. 기존 1.2.2의 화면과 권한 정책을 유지하며 Next.js App Router와 React로 이전했습니다. 보고서의 UI Design 부분은 기준에서 제외하고, 기존에 반영한 기능 요구사항과 팀 모듈 연결 범위를 유지합니다.

## 유지한 것

사이드바의 `SEA THE ANSWER` 표기, 남색 사이드바·청록색 버튼·흰 카드, 폰트, 5개 메뉴 구조를 유지했습니다. 기존 CSS는 `src/styles/base.css`와 `src/styles/workspace.css`로 옮겼습니다. 새 메뉴를 추가하거나 화면을 다시 디자인하지 않았습니다.

## 구현 구조의 변경

- 화면은 `src/app`의 페이지와 `src/views`의 React JSX로 구성합니다. 기존 HTML 문자열을 화면에 삽입하지 않습니다.
- 문서·보고서는 개별 URL로 이동하며 새로고침과 브라우저 뒤로가기를 지원합니다.
- 공통 사이드바, 로그인 상태, 입력 초안과 대화상자는 `src/workspace`에서 관리합니다.
- 기존 Node.js API·SQLite·검색·계산·백업 로직을 유지합니다. 실행기가 Next.js 화면 서버와 기존 API 서버를 함께 실행하고 같은 접속 주소로 연결합니다.
- PDF.js와 글꼴은 `public`에 포함합니다. 설치·빌드 이후 기본 기능은 로컬에서 사용할 수 있습니다.

UI만 있는 가짜 계정이나 가짜 저장 버튼을 넣지 않았습니다. 계정·데이터·보고서·승인·백업은 로컬 서버에서 처리합니다. 운항 예시는 명시적으로 등록한 경우에만 가상 자료로 표시합니다.

CII 전문 계산, Local LLM, 교차 언어 RAG 품질, 규정 적용 자동 판정, 공식 제출 서식은 별도 팀 구현 영역입니다. 현재 화면은 데이터 부족과 미연결 결과를 구분해서 표시합니다. 기능의 정확도·응답 시간 목표 달성은 최종 팀 데이터와 모듈로 평가해야 합니다.

1.2.2와 동일한 DB 형식을 사용합니다. 기존 서버를 정상 종료하고 새 폴더로 `data`와 필요한 `.env`를 복사하면 기존 자료를 이어서 사용할 수 있습니다. 더 오래된 DB에 대한 기존 이전 로직도 유지했습니다. 자세한 순서는 README를 따르세요.
