# UI 보완 기록 — 1.2.2

2026-09-30. 보고서의 UI Design 부분은 기준에서 제외했습니다. 기능 요구사항 3.1, 동작환경 4.1, 기능·통합 평가를 기준으로 보완했습니다.

## 유지한 것

사이드바의 영문 표기는 `SEA THE ANSWER`로 변경했습니다. 기존 `style.css`, 남색 사이드바·청록색 버튼·흰 카드, 폰트, 5개 메뉴 구조를 유지했습니다. 대형 대시보드나 새 메뉴를 늘리지 않고 기존 화면과 입력 창을 확장했습니다.

| 이력·로그 | 당시 답변 재열람, 관리자 질의·변경·오류·계산 로그와 필터 |
| 백업·복구 | 전체 백업 목록·일시·버전, 다운로드·가져오기, 복구 확인·직전 보관·자동 백업 |

UI만 있는 가짜 계정이나 가짜 저장 버튼을 넣지 않았습니다. 계정·데이터·보고서·승인·백업은 로컬 서버에서 처리합니다. 운항 예시는 명시적으로 등록한 경우에만 가상 자료로 표시합니다.

CII 전문 계산, Local LLM, 교차 언어 RAG 품질, 규정 적용 자동 판정, 공식 제출 서식은 별도 팀 구현 영역입니다. 현재 화면은 데이터 부족과 미연결 결과를 구분해서 표시합니다. 기능의 정확도·응답 시간 목표 달성은 최종 팀 데이터와 모듈로 평가해야 합니다.

1.1.1 기존 DB는 새 테이블을 추가하여 이전합니다. 소유자가 없는 기존 `current` 초안은 자동 설정한 관리자에게 연결합니다. 수정 전 폴더를 보관하고 새 폴더에서 업데이트하는 절차는 README를 따르세요.
