## 서버·DB 회귀 검증

기존 테스트를 유지하고 현재 소스 경로와 화면 서버 연결 구조를 반영했습니다. 문서 인덱싱·검색·버전·인용·권한, 계산 입력 검사, SQLite 재연결 후 영속성, CSV 원자적 처리, 보고서 저장 충돌·검토·승인, 백업 무결성·복구·자동 백업, 공개 사용자와 관리자 권한, 기존 계정·소유권 이전을 검증했습니다.

화면 서버를 실행하지 않은 `node server.mjs`는 기본 주소에 실행 안내(503)를 반환하고 API만 제공합니다. 완전한 앱은 `npm start` 또는 `npm run dev`로 실행하는 것이 현재 계약입니다.

## 검증 범위의 한계

- Windows의 `start.cmd`, PowerShell 실행기와 실제 다른 기기의 LAN 접속은 이 Linux 환경에서 직접 실행하지 않았습니다. Windows 전용 테스트는 프로젝트에 포함되어 있습니다.
- 모바일 검증은 Chromium의 화면 크기 조정이며 실제 휴대폰 터치·Safari·Edge 전체 호환성 검증은 아닙니다.
- 텍스트 PDF의 추출과 원문 응답은 확인했지만 임의의 스캔 PDF·복잡한 표·브라우저 내장 PDF 뷰어 전체를 검증하지 않았습니다. OCR은 구현 범위 밖입니다.
- 실제 외부 LLM은 호출하지 않았습니다. 모델 실패·인용 검증은 모의 응답을 이용한 서버 테스트입니다.
- 공식 CII 계산, 규정 적용 자동 판정, 검색 Recall·응답 시간 목표, 번역 품질, 공식 보고서 양식은 별도 팀 모듈과 최종 데이터로 검증해야 합니다. 이번 변경은 기존 UI와 API를 Next.js 구조로 이전한 작업입니다.
