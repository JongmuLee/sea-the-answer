## 검증의 한계

DOM 검증은 HTML 구조·버튼 이벤트·서버 연결을 검증합니다. 실제 브라우저의 픽셀 배치, PDF 내장 뷰어, 모바일 터치 및 파일 선택 창을 직접 조작한 시각 QA는 아닙니다. 반응형 CSS와 원래 디자인을 유지했으며 실제 Chrome/Edge에서는 최종 확인이 필요합니다.

PDF.js 추출 코드는 Node 테스트 환경의 Canvas 보조 객체를 이용해 확인했습니다. 제공된 보고서는 페이지 30개·빈 텍스트 페이지 0개가 추출되었으며 5페이지의 기능 요구조건 텍스트도 확인했습니다. 임의의 스캔 PDF·복잡한 표의 추출 정확도 전체를 보장하지 않습니다.

Windows 실행기 테스트는 Linux 환경이라 건너뛰었습니다. 실제 외부 LLM 호출은 하지 않았고 모델 실패·인용 검사는 모의 응답으로 검증했습니다. 검색 Recall, 15초 응답 목표, 번역 품질, 공식 CII·법규 적용·공식 보고서 양식 충족은 최종 팀 모듈과 데이터로 별도 평가해야 합니다.
