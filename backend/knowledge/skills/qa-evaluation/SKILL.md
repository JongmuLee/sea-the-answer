# 질의·응답 평가

## 평가 대상

내 질의 이력의 answer_id를 선택한다. 서버가 소유자와 현재 문서 열람 권한을 다시 확인한다. 타인의 응답이나 현재 권한이 없는 문서 내용을 평가 결과로 노출하지 않는다.

## 자동 점검

- 인용된 chunkId가 저장된 evidence에 있고 quote가 원문에 존재하는지 확인한다.
- 선택 문서 제한 응답이면 evidence의 모든 document_id가 선택 범위 안인지 확인한다.
- MRV 참고 계산 응답이면 저장 입력/참조 스냅샷으로 기존 Python 계산 함수를 다시 실행해 상태·참고값·공식 CII null·참고 전용 표식을 대조한다.
- 적용하지 않는 항목은 not_applicable로 남긴다. 실패를 통과로 처리하거나 빈 답변에 만점을 주지 않는다.

## 사람이 검토할 부분

원문이 실제로 주장을 뒷받침하는지, 질문에 충분히 답했는지, 자료가 사실인지, 규정이 적용되는지는 별도 검토다. 자동 검사를 전체 정답률이나 법정 정확도로 표현하지 않는다. 결과는 pass/fail/not_applicable/manual_review_required를 구분하고 근거를 설명한다.

테스트 자료를 모델 학습·지침 개선에 사용했다면 독립 홀드아웃이라고 부르지 않는다. 이 스킬은 모델 재학습이나 외부 평가 서비스 전송을 하지 않는다.
