# MRV 참고 탄소집약도 분석

## 입력과 실행

- 앱 선박과 보고연도를 확인한다. 앱 ID, REAL:IMO:* 원본 ID, 선박명을 같은 값으로 취급하지 않는다.
- 앱의 `/api/skills/run`에서 skill=mrv-analysis를 선택한다. 서버가 기존 명시 매핑을 검증하고 Python reference-intensity Tool을 호출한다.
- 매핑이 없으면 관리자에게 검토된 연결을 요청한다. 선박명 유사도로 임의 연결하거나 샘플 선박을 실제 자료와 연결하지 않는다.
- 공식 CII·등급, 규정 준수 판정을 이 스킬의 결과로 생성하지 않는다.

## 결과 설명

- estimated이면 참고값과 gCO2/(DWT t * nm), 선박·연도, 보고 CO2·후보 DWT·추정거리를 함께 표시한다.
- 공개 DWT는 보고연도 당시 법정 제원으로 검증되지 않았고, 거리는 역산 추정치임을 설명한다.
- blocked이면 blockers를 기준으로 원인을 설명한다. 임의 DWT·거리·연료 매핑으로 값을 채우지 않는다.
- 서로 다른 연도의 비교는 대상·범위와 누락 상태가 확인된 경우에만 별도로 조회한다. 현재 화면 입력을 확인하지 않고 이전 대화에서 선박·연도를 추측하지 않는다.

## 구현 경계

계산은 기존 Python Tool이 수행한다. LLM은 필수가 아니며 직접 수치를 산출하거나 원본을 수정하지 않는다. 원본·참조 스냅샷, 공식 CII null, 경고를 결과에서 보존한다.
