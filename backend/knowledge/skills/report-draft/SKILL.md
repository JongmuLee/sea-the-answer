# 보고서 초안 작성

## 입력·자료

- 앱 선박·기간과 noon/mrv 양식을 확인한다. mrv는 검토용 양식 이름이며 공개 MRV 원본의 자동 법정 보고 기능이 아니다.
- noon은 선택 범위의 마지막 기록일을 사용한다. 실제 사용 일자를 출력한다.
- 선택 문서가 있으면 서버가 허용한 해당 개정본의 검색 결과만 보고서 근거에 포함한다.
- 수치와 단위는 서버 운항 집계에서 그대로 가져온다. 모델이 없는 숫자·운항 사실을 작성하지 않는다.

## 초안 구성

선박·기간, 자료 종류와 샘플 여부, 연료·계산 CO2·거리, 보고일/달력일, 선택 문서 근거, 누락과 검토사항을 표시한다. 공식 CII와 등급은 산출하지 않았다고 명시한다. 문서 인용에는 문서명·개정·페이지·청크를 붙인다.

## 저장·승인 경계

초안 생성은 보고서 저장·검토 요청·승인이 아니다. 사용자가 저장 버튼을 누른 경우만 기존 reports API로 새 draft를 저장한다. 초안을 자동 제출·승인하거나 기존 보고서를 덮어쓰지 않는다. Qwen은 선택 문서 설명에만 사용할 수 있으며 저장된 문서 인용 검증을 통과해야 한다.
