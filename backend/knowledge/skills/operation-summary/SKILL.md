# 운항 실적 요약

## 입력

앱 선박과 시작일·종료일을 확인한다. 날짜 범위는 양끝을 포함하며 최대 366일 차이다. 연간 공개 MRV 보고값과 앱 일별 관측을 섞지 않는다.

## 실행·출력

- public.operations의 해당 선박·기간 행만 사용한다. 계산은 서버 코드에 맡긴다.
- 연료 합계(t), 각 행의 연료×입력계수 합계인 계산 CO2(t CO2), 거리 합계(nm), 기록 수와 보고일 수를 표시한다.
- 속력은 기록별 단순 평균이며 시간 가중 평균이라고 부르지 않는다.
- 누락된 날짜가 있으면 해당 일수를 알리고 연간·기간 전체가 완전하다고 표현하지 않는다. 누락을 0 사용량으로 간주하지 않는다.
- sample 표식이 있으면 가상 예시임을 표시한다. 공개 실제 선박의 실적으로 설명하지 않는다.
- 단순 기간 집약도를 공식 CII나 등급으로 표시하지 않는다.

## 부족·오류

자료가 없으면 수치 실적이 없다고 안내하고 선박·기간 선택을 확인한다. 임의 기간 변경이나 원본 기록 생성은 하지 않는다. 이 스킬은 DB 원본을 수정하지 않으며 실행 결과와 이력만 저장한다.
